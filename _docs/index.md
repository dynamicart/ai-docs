# _docs — Knowledge Bundle

> This directory is the project's [OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)-conformant knowledge bundle: every TASK, JOURNAL, ADR, and MODULE is a concept, cross-linked with standard markdown links. See `../agent.md` for the generated, agent-facing digest of the stable facts, and `PROJECT-OVERVIEW.md` for the full human-facing project map. Generated by `/project-sync` — do not edit by hand.
