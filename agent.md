## About the Project

AI Docs is a Markdown-based framework for AI-driven documentation automation (tasks, journals, ADRs via `/` commands, plaintext kanban, OKF v0.2 shared knowledge bundle). Includes a zero-dependency HTML/JS viewer (`tool/docs-viewer.html`) for kanban, reader, and search views without Obsidian.

## Tech Stack

- **Docs:** Markdown + YAML frontmatter (OKF v0.2), `_docs/` doubles as Obsidian vault
- **Tooling:** Vanilla HTML5/JS (inline CSS/JS, no build, no external deps)
- **Agents:** Antigravity, Claude Code, OpenCode (workflows as `/` commands)
- **Other:** Git

## What you need to know before working

- **Zero blind probing:** Do not run shell env probes (e.g. `php -v`, `node -v`) or discovery subagents before checking Tech Stack and `_docs/arch/` (e.g. `STACK.md`).
- `_docs/` is an OKF v0.2 bundle: use bundle-relative links (`/tasks/...`), never `[[wikilinks]]`.
- **Never hand-edit generated files:** `_docs/BOARD.md`, `_docs/index.md`, `_docs/PROJECT-OVERVIEW.md`, and `agent.md` (above boundary). Update board via TASK plan checkboxes.
- `_docs/modules/*.md` are durable references: create/update only via manual, human-approved `/module-sync`.
- `_docs/log.md` is append-only (maintained by workflows; never rewrite retroactively).
- Record every major decision in the active TASK file or as an ADR in `_docs/DECISIONS-LOG.md`.
- **Workflows:** Execute `.agents/workflows/` definitions as written; never invoke unrequested workflows.
- Always run `/task-close` upon task completion (see `.agents/rules/style-guide.md` §3).
