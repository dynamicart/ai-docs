## About the Project

AI Docs is a Markdown-based framework for AI-driven documentation workflow automation (TASK/JOURNAL/ADR management via `/` commands, plaintext kanban, OKF v0.2-conformant `_docs/` knowledge bundle, cross-agent "Shared Brain"). This project applies the template and ships its first tool: the standalone, server-less HTML/JS **Docs & Board Viewer** (`tool/docs-viewer.html`) that loads a `_docs/` folder and renders kanban / reader / search views without Obsidian.

## Tech Stack

- **Docs:** Markdown + YAML frontmatter (OKF v0.2), `_docs/` as Obsidian-compatible vault
- **Tooling (TASK-001):** Vanilla HTML5/JS (inline CSS/JS, no build, no external deps)
- **Agents:** Antigravity, Claude Code, OpenCode (workflows via `/` commands in `.agents/workflows/`)
- **Other:** Git, `.agents/skills/` + `.agents/rules/style-guide.md`

## Key Decisions

- **ADR-001 (accepted, 2026-08-20):** The viewer's kanban view is built primarily from TASK frontmatter, with a BOARD.md-parse fallback mode switch — no second source of truth.
- **ADR-002 (accepted, 2026-08-20):** Folder loading uses a combination of `webkitGetAsEntry()` + `webkitdirectory` (instead of the Chromium-only `showDirectoryPicker()`), with a fallback to `dataTransfer.files`.
- **ADR-003 (accepted, 2026-08-20):** Viewer localization uses an in-file `I18N` dictionary + `data-i18n` attributes (no build step), default language English, persisted in `localStorage`; canonical data values stay English in both languages.

## What you need to know before working

- Full development documentation lives in the `_docs/` folder.
- `_docs/` is an OKF v0.2 bundle: every TASK/JOURNAL/ADR is a concept with `type` frontmatter; use bundle-relative links (`/tasks/...`), never `[[wikilinks]]`.
- `_docs/BOARD.md` is a generated view (via `/board-sync`) — never edit it by hand; check off "Approach / Plan" items in the TASK file instead.
- `_docs/modules/*.md` are durable references, updated only via `/module-sync` (manual, human-approved).
- Record every major decision in the TASK file (or as ADR in `DECISIONS-LOG.md`).
- The docs viewer (`tool/docs-viewer.html`) is the finished tool for browsing the bundle — load it in a browser and drop the `_docs/` folder onto it.
- Always run `/task-close` upon task completion, then `/agent-sync` to refresh this file.
